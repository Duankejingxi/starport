# 星港 Starport — 火星城市建造游戏

浏览器里的火星城市建造游戏。纯前端，Canvas 渲染，零依赖。**纯机制，无剧情。**

## 核心循环
出生在火星 → 找资源 → 建房子 → 扩大城市

## v0.1 内容
- 20×20 火星地图：平地/岩石/环形山地形
- 3 种资源：铁矿 / 冰水 / 稀土（随机分布）
- 玩家：点击移动 / WASD，在资源点上采集
- 3 种建筑：居住舱（+4人口上限）、太阳能板（+3电力）、采矿机（自动产铁，需2人口）
- 人口系统：每20秒+1，随上限增长

## 后续规划
- v0.2: 城区/道路系统
- v0.3: 交通/物流
- v0.4: 工业链

## 文件
- `index.html` — 入口
- `styles.css` — 火星主题
- `map.js` — 地图生成与渲染
- `player.js` — 玩家移动/采集/背包
- `build.js` — 建筑定义与放置
- `game.js` — 主循环与人口系统
