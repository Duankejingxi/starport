# 星港：新家园 Starport: New Home

> 2089 年。你是第一个踏上火星的人，但不会是最后一个。

一款**第一人称**火星开拓游戏。在红色荒原上挖矿、建造、制造武器，抵御长夜里的锈蚀蛛，迎接一批又一批来自地球的移民。最后启动大气改造塔，亲眼看着火星的天空变蓝，下起第一场雨。

## 怎么玩

直接用浏览器打开 `index.html` 就能玩（推荐 Chrome / Edge，需要键盘和鼠标）。
开启 GitHub Pages 后也可以在线玩：https://duankejingxi.github.io/starport/

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 鼠标 | 环视 |
| Shift | 冲刺 |
| 空格 | 跳跃；造出喷气背包后在空中按住可以飞行 |
| 左键 | 采矿 / 射击 / 放置建筑 |
| 右键 | 取消建造 |
| 1 / 2 | 采矿激光 / 等离子步枪 |
| B | 建造菜单 |
| R / 滚轮 | 旋转建筑 |
| E | 与居民交谈、打开制造工坊 |
| X | 拆除建筑（按两次确认，返还 50%） |
| F | 手电筒 |
| Esc | 暂停 |

## 五个章节

1. **着陆**：着陆舱只能在附近给你补氧。先采集铁矿、硅晶、水冰，建起太阳能和制氧站。
2. **第一个家**：建居住穹顶、温室、水冰提取器和着陆场。条件满足后，移民飞船就会降落。
3. **长夜**：夜里，锈蚀蛛从地底钻出来。建制造工坊，造等离子步枪，建防御炮塔。
4. **扎根**：去远方的紫色晶体矿脉开采钛（那里有更强的守卫），点亮聚变反应堆。
5. **新家园**：建造大气改造塔，让火星真正成为家。

每一位移民都有名字、职业和想对你说的话。走近他们按 E 听听。

## 生存要点

- 氧气会持续消耗。回到着陆舱、制氧站或居住穹顶附近会自动补氧和回血。
- 太阳能夜间只剩四成功率，所以要多建几座，或者造反应堆。断电时按优先级供电：制氧站 → 炮塔 → 住房 → 其他设施。
- 建筑被锈蚀蛛打坏后会停机，白天会自动修复。
- 第 2 天起会有沙尘暴：能见度下降，氧气消耗加快。
- 游戏每 45 秒自动保存（存在浏览器的 localStorage 里），也可以在暂停菜单里手动保存。

## 开发

纯前端，基于 [three.js](https://threejs.org/)，用 esbuild 打包成单个 `dist/game.js`，所以不需要服务器也能直接打开。

```bash
npm install
npm run build   # 打包到 dist/game.js
npm run dev     # 监听源码变化，自动重新打包
```

| 文件 | 内容 |
|---|---|
| `src/main.js` | 启动、主循环、存档、事件、互动 |
| `src/terrain.js` | 程序生成的火星地形、陨石坑、大气改造后的绿化 |
| `src/sky.js` | 昼夜循环、火星蓝色日落、星空、火卫一和火卫二 |
| `src/player.js` | 第一人称移动、氧气 / 生命 / 能量 |
| `src/tools.js` | 采矿激光、等离子步枪、建造工具、手电筒 |
| `src/buildings.js` | 11 种建筑、电力与生命维持、放置预览 |
| `src/resources.js` | 铁、硅、冰、钛矿点 |
| `src/combat.js` | 弹道、锈蚀蛛 AI、钛矿守卫 |
| `src/colony.js` | 移民飞船、居民行为与对白 |
| `src/story.js` | 章节目标、无线电、制造配方、沙尘暴 |
| `src/models.js` | 所有 3D 模型（全部由代码生成） |
| `src/ui.js` | 界面、小地图、罗盘、菜单 |
| `src/audio.js` | 全部合成的音效与环境音乐 |

浏览器地址加上 `?debug` 会跳过鼠标锁定，并在控制台暴露 `__dbg` 调试接口。
