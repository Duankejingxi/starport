# 星港 Starport — 火星城市建造游戏

出生在火星 → 找资源 → 建房子 → 人口自动涨 → 建城市 → 不断扩大 → 升级 → 建发射台通关。

纯玩法，无剧情。纯原生 JS/Canvas，零依赖。

## v1.0（完整基础循环）
- **8 种资源**：铁矿/冰水/稀土/水/食物/电力/钢材/科技点
- **12 种建筑 × 3 级**：居住舱/太阳能板/采矿机/抽水机/冶炼厂/温室/水厂/实验室/道路/医院/指挥中心/发射台
- **人口**：自动增长，需水+食物+电力
- **地图**：30×30，9 扇区（中心解锁，8 个花铁解锁）
- **城市评级**：聚落→城镇→都市→大都会→星港
- **胜利**：建成发射台
- 存档：localStorage 自动存
