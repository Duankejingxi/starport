# 星港：新家园 Starport: New Home

> 2089 年。你是第一个踏上火星的人，但不会是最后一个。

一款**第一人称**星球开拓游戏。在红色荒原上挖矿、建造、制造武器，抵御长夜里的锈蚀蛛，迎接一批又一批来自地球的移民。城市从前哨站一路成长为「星港」，领地不断扩张。火星的天空变蓝之后，乘殖民舰飞向木卫二·欧罗巴，再飞向一千二百光年外的开普勒-442b。

## 怎么玩

直接用浏览器打开 `index.html` 就能玩（推荐 Chrome / Edge，需要键盘和鼠标）。
开启 GitHub Pages 后也可以在线玩：https://duankejingxi.github.io/starport/

## 画面

- **地形**：平滑着色，叠加程序生成的多层细节：沙纹、陡坡上的岩层条纹、近景凹凸。玩家周围铺满碎石。
- **材质**：建筑、设备和岩石都用程序生成的 PBR 贴图，有面板接缝、铆钉、尘垢流痕、划痕和粗糙度变化。
- **光照**：天空实时生成环境反射，金属、玻璃和太阳能板会映出天空的颜色；指数雾让远山自然淡出。
- **后期**（高画质）：泛光、电影调色、暗角、细微胶片颗粒和边缘色散。
- **开场**：字幕结束后，镜头在地面仰望你的着陆舱喷着火焰从天而降，落地扬起尘土，再推进到第一人称。点击或按空格可以跳过。
- **字体**：Google 字体改为异步加载，连不上时自动使用系统中文字体，不会卡住页面。

## 三颗星球

- **火星 · 新家园**：红色荒原、蓝色日落、沙尘暴。完成大气改造后，天空会变蓝。
- **木卫二 · 欧罗巴**：冰原与赭红色的冰裂纹，木星像一轮巨大的月亮挂在天上。太阳很远，太阳能只有一半效率，重力也低。
- **开普勒-442b**：两个太阳，夜里会发光的伞菇森林，天边有一颗带光环的巨行星。在这里建起文明纪念碑，就是最终结局。

去新星球时，所有装备都会同步过去，还能随舰带走一部分物资。之前的殖民地会继续自主运转。

**星际航线**：任何一颗星球建好星际发射台后，靠近按 E 就能打开星图，可以前往新星球，也可以回到任何一座已经开拓的城市。每颗星球的进度都会单独保存。

## 火星的六个章节

1. **着陆**：着陆舱只能在附近给你补氧。先采集铁矿、硅晶、水冰，建起太阳能和制氧站。
2. **第一个家**：建居住穹顶、温室、水冰提取器和着陆场。条件满足后，移民飞船就会降落。
3. **长夜**：夜里，锈蚀蛛从地底钻出来。建制造工坊，造等离子步枪，建防御炮塔。
4. **扎根**：去远方的紫色晶体矿脉开采钛（那里有更强的守卫），点亮聚变反应堆。
5. **新家园**：建造大气改造塔，让火星真正成为家。
6. **星辰大海**：把城市发展到「星港」，建造星际发射台，飞向下一颗星球。

每一位移民都有名字、职业和想对你说的话。走近他们按 E 听听。

## 漫游车与随机事件

- **加压漫游车**：在制造工坊制造，出厂后停在工坊旁边。走过去按 E 上车，W/S 是油门，A/D 转向，Shift 加速（最高约 100 km/h），空格刹车。车舱带气压，坐在车里会自动补氧，适合长途勘探。开快了还能撞飞锈蚀蛛，冲过坡顶会腾空。去新星球时漫游车会一起跟过去。
- **流星雨**：从第 2 天起，夜里有机会出现。会有几颗陨石坠落在你附近，坠落点会留下钛矿。

## 夜空与广场

- **极光**：夜里天边会出现缓缓飘动的极光。火星上淡而偏蓝绿（火星确实有极光），木卫二是蓝紫色，开普勒最为壮观。
- **中央广场**：城市升到「定居点」后解锁。广场中央有一座旋转的全息地球。天黑后，大部分居民会走到广场，围着地球站成一圈。
- **拍照**：按 P 进入拍照模式，界面隐藏，上下出现电影遮幅。按 1～4 切换原色、胶片、黑白、冷调滤镜，按 Enter 把照片保存到电脑，底部会印上星球、日期和人口。

## 伙伴：小星

一个跟在你右后方飞行的小机器人。夜里它会亮灯帮你照明；氧气不足、锈蚀蛛靠近、发现钛矿时它会出声提醒，闲下来还会聊几句和当前星球有关的话。按 Q 让它发出扫描脉冲：一圈光波从你脚下扩散到 140 米外，范围内所有矿点会亮起彩色标记，隔着山丘也能看见，持续 10 秒，冷却 12 秒。

## 自动化、升级与晶潮

- **采矿无人机站**：每座站点派出 2 到 4 架无人机，自动飞到 100 米内的矿点采矿，再把资源运回来。升到 3 级后无人机会去采钛。
- **建筑升级**：对准建筑按 U 可以升到 3 级。发电、住房、氧气、食物和水的产出分别提升到 1.6 倍和 2.2 倍，耐久、补氧半径、炮塔射程和伤害也会提升。建筑外观会长大，屋顶亮起等级灯。
- **晶潮之夜**：每第 4 个夜晚是晶潮，锈蚀蛛数量接近翻倍，入夜不久巨型 Boss「晶母」会破土而出。它的踩踏会震飞附近的人，砸建筑也更狠。击败它能拿到大量钛和硅。

## 探索与收集

- **遗迹**：每颗星球上都散落着几处遗迹，罗盘上的「?」会指出最近一处未发现遗迹的方向和距离。火星上能找到真实的探测器——祝融号、机遇号、海盗一号、机智号；欧罗巴和开普勒上则有各自的谜团。走近按 E 调查，会听到它的故事，还能拿到一些资源。
- **成就**：一共 27 个成就，跨星球累计。暂停菜单里可以查看。
- **城市道路**：每座新建筑会自动修一条路连到最近的邻居，路边的引导灯夜里会亮起来。
- **星球景观**：火星有游荡的尘卷风，欧罗巴的冰裂缝会定时喷发冰泉，开普勒的夜空里漂浮着发光的水母，还会下雨。

## 生存要点

- 氧气会持续消耗。回到着陆舱、制氧站或居住穹顶附近会自动补氧和回血。
- 太阳能夜间只剩四成功率，所以要多建几座，或者造反应堆。断电时按优先级供电：制氧站 → 炮塔 → 住房 → 其他设施。
- 建筑被锈蚀蛛打坏后会停机，白天会自动修复。
- 第 2 天起会有沙尘暴：能见度下降，氧气消耗加快。
- 电脑配置一般的话，可以在暂停菜单里把画质调到「中」或「低」。
- 游戏每 45 秒自动保存（存在浏览器的 localStorage 里），也可以在暂停菜单里手动保存。

## 开发

纯前端，基于 [three.js](https://threejs.org/)，用 esbuild 打包成单个 `dist/game.js`，所以不需要服务器也能直接打开。

```bash
npm install
npm run build   # 打包到 dist/game.js
npm run dev     # 监听源码变化，自动重新打包
```

| `src/drones.js` | 采矿无人机 |
